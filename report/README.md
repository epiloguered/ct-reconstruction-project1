## 阅读顺序

正文先看第四节的指标和选参协议，再看第五、六节的全部噪声条件基线／正则化结果，最后看第七、八节的少角度实验。附录保存DIP、TGV和小波探索，第九节为40行最佳结果主表，结论集中在第十节。指标理论与扩展方法在对应段落引用论文，参考文献统一编号。

## 结果依据

`outputs/final/baseline_regularization.csv` 是原90角主结果总表，包含LS、ART与六个正则化方案。其他CSV分别记录传统稀疏角度、DIP、非负TV／小波／PnP方法和90角对照。`outputs/final/sources.json` 保留15个来源的哈希；每条指标记录能追踪原输出文件。

固定预算终点是新方法主表口径。全部保存终点中按真值挑选的可达结果另列，不能与主表混用，也不能理解为实际扫描中未知真值时的自动选择。原90角参照始终取原正则化输出，后续90角重跑只用于该阶段的受控角度趋势分析。

## 修改与再生成

修改正文：`tools/build_experiment_report.py:compose()`。

修改汇总数据或科学图像：`tools/build_report_assets.py`。

修改每种方法最佳结果的选择规则：`tools/build_best_results.py`。该脚本每数据集每方法取最低NRMSE，三指标保留同一记录，生成 `outputs/final/best_by_method.csv`。

修改参考文献编号：同时检查 `tools/prepare_report_bibliography.py` 和正文引用。正式文献记录、核查说明位于 `outputs/report_build/`。

构建、Word渲染和检查命令见[实施记录第16节](../docs/实验实施记录.md#16-作业报告整理与核验2026-10-11)。生成脚本会覆盖Word和Markdown；如果直接在Word填姓名或修改文字，请保留副本，或同步修改生成脚本。

本次只整理和核验既有实验，没有新增训练。QA页图、核验JSON和复审记录均保存在 `outputs/report_build/`，无需作为报告附件逐个提交。
