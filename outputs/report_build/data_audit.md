## 2. 三种90角不能混用

1. **原90角基线**：`outputs/<dataset>` 与 `outputs/regularized/<dataset>`；用户要求质量参照来自这里。LS+TV为FISTA600、无非负约束、零初始化；ART+TV为5轮、非负、零初始化。
2. **稀疏主实验重跑90角**：`outputs/extension/classical`；L2网格改成按测量行数归一化，LSQR数值也有变化。比较角度趋势时应使用这套90/45/30/15角内部一致的表，不插入原90角数值。
3. **后续90角控制组**：`outputs/improvements/summary/classical_final_metrics.csv` 的90角 `TV_control`，原始—对偶法12000步；可用来比较同求解器的少角度改进，不能改称“原90角LS+TV”。

具体数值：Shepp30dB原LS+TV NRMSE=`0.0687974295`，后来90角TV_control=`0.0682485725`；XCAT30dB原LS+TV=`0.1066168150`，后来TV_control=`0.1064948185`。虽然接近，实验身份仍不同。原XCAT15dB LSQR=`121.7019722`，稀疏扩展重跑90角LSQR=`122.2795`（原始精确值在JSON）；不能把两者错写成同一次运行。

## 4. 稀疏传统与DIP正文结论

- 稀疏传统主实验完整32条件中，最低NRMSE方法为LS+TV **28/32**、ART+TV **4/32**。ART+TV四次胜出均为Shepp64：30角15/20dB、15角15/20dB。角度减少总体增加重建困难，但结果不是每个方法每档噪声都单调（病态LSQR尤其如此）。完整160条应放正文分数据表或附录，避免只展示20/30dB。
- DIP主表使用 **fixed2000、三个种子均值±样本标准差（ddof=1）**，不是最佳种子、不是置信区间。DIP+TV的平均NRMSE在8/8条件低于DIP，平均SSIM在8/8条件更高。
- 相对同阶段LS+TV，DIP+TV在Shepp的4/4条件平均NRMSE更低（降低3.3%–34.9%），在XCAT的4/4条件更高（误差高5.0%–11.5%），其SSIM却均更高。不能宣称神经方法普遍胜过传统方法。Shepp30角20dB ART+TV=0.3047仍低于DIP+TV=0.3077。
- 原DIP固定β=0.01（20dB）/0.001（30dB），GT不进入损失、幅度尺度或固定终点停止；传统正则化使用GT幅度与参数网格选择，两类选参和约束口径不同。
- 后续非负TV在8/8少角度条件NRMSE低于相同求解器TV控制；TGV仅5/8更低，部分差别小于有实际解释力的量级。投影验证截点在6/8条件优于同次留出训练fixed，却仅1/8优于历史全投影fixed，不能写成整体质量提升。

## 6. 需写进报告的方法限制与复现事实

- 所有图像保持原64²/128²分辨率和F顺序；A/b同步抽取完整角度探测器行块；没有重新生成噪声。少角度实测SNR变化来自同一给定噪声的子集统计。7/8/9/10角集合未必嵌套，不能称全局最少角度。
- 图像指标使用未经裁剪、配准或亮度拟合的原向量；显示才使用GT范围。PSNR与NRMSE对同一GT由相同平方误差决定，非独立证据；SSIM侧重不同。
- 固定预算不代表严格收敛；LS+L1/TV、原始—对偶TV/TGV、PnP、DIP各有有限预算和模型/数值限制。不能跨算法直接把迭代步数等同计算量。
- 最新PnP初始化、非负约束、搜索范围和预算均不同于原90角LS+TV/ART+TV。新流程成本含TV12000起点及9参数候选，不能只计160步。GT用于幅度和参数/终点选择，未直接把GT像素当重建输入。
- 历史扩展审计 `passed/7953`；后续改进 `passed/3236`；最新审计 `passed_with_replay_variation/5238`、`artifact_verification=passed`、`strict_replay_passed=false`；原90角fullview审计 `passed/3783`。这些是已保存历史审计，本次未重新运行相应脚本/测试。
- 4线程BM3D的严格重跑相对误差1e-6未通过；三条件各两次重跑保留，数组差异约0.516%–1.356%。Shepp10角30dB常规160的保存NRMSE0.114672，两次重跑0.113101/0.114641。重跑差异不应混成不同噪声样本或网络种子标准差。
- 原90角没有历史输入hash清单；当前保存基线四指标在当前GT/b上吻合，是口径一致的证据，不能证明历史文件从未改动。当前只读复算567数组证明保存值/输入/指标一致，不证明优化过程可逐位重跑。
- 仅两张GT、每档给定单次噪声，不能形成独立训练/测试泛化评估；没有真实扫描剂量或临床可接受性模型，不能换算实际剂量下降比例。
