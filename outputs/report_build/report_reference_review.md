## 需要修正的项

### 1. 第135行：L 不能表述为已核证的谱范数上界

- 现文：`L为估计的‖A‖₂²上界`。
- 证据：`run_regularization.py:spectral_lipschitz()` 使用80步幂迭代的 Rayleigh 商再乘1.05；源码也明确这不是对任意矩阵的严格上界证明。引用 FISTA [4] 不能补足本项目未证明的上界性质。
- 建议替换：`L由80步幂迭代估计‖A‖₂²后乘1.05得到，作为带5%余量的步长尺度；未将它作为严格上界证书。`
- 同段的 `λ=p·L·R` 对当前 LS+TV 正确。附录第219行泛称 `LS的λ=p·L·R` 时应限定为 `LS+L1/TV`；LS+L2直接搜索λ，不使用这一换算。

### 2. 第92—94行：区分局部 SSIM 公式和最终全图均值，补齐常数与样本统计

- 第92行公式给出单个窗口的 SSIM，而本项目记录的是有效内域上局部 SSIM 的平均。将公式左侧写为 `SSIM局部(x,y)`，然后说明 `SSIM报告值=有效内域上局部SSIM的算术平均`。
- 补充 `C₁=(K₁R)²，C₂=(K₂R)²`；仅给K₁/K₂值，尚未定义公式中的C₁/C₂。
- 第94行 `样本协方差` 改为 `样本方差与协方差（49个像素，以48为分母）`。本地源码对两种方差及协方差均乘49/48，并非只校正协方差。
- `7×7均匀窗口`、`K1=0.01，K2=0.03`、`剔除3像素边框后取平均` 均与本地0.26.0源码一致，保留即可。

### 3. 第94行：收窄“原论文总体协方差”的归因

- 现文：`原论文常用11×11高斯窗口σ=1.5及总体协方差`。
- 问题：Wang等 [6] 的一般统计推导和后面的高斯加权数值设置应分开；原文一般定义曾使用样本统计，不能笼统地将整篇论文概括为“总体协方差”。原文§III-C式(14)—(17)使用归一化高斯权重直接计算加权二阶统计；库文档 [14] 将对应选项称为 `use_sample_covariance=False`。
- 建议替换：`Wang等原文§III-C的数值设置采用11×11、σ=1.5的归一化高斯权重计算局部统计；scikit-image文档建议以gaussian_weights=True、sigma=1.5、use_sample_covariance=False并显式指定data_range来匹配该实现。本项目使用默认均匀窗和样本统计，因此只引用其指标定义与思想，不声称数值设置完全相同。`
- 为节省正文篇幅，可把完整匹配参数移到脚注，正文保留两者差异。

### 4. 第228行：归一化目标须限定为纯 TV，补齐非负约束和d

- 现文将 `½‖Bu−d‖²+p·TV(u)` 泛称为“新原始—对偶方法”的目标；这不能同时完整表示小波+TV和TGV。
- 证据：`run_min_angles.py:wavelet_tv()` 还含 `ratio·p·‖W_detail u‖₁`；`run_sparse_improvements.py:primal_dual()` 的TGV使用辅助变量v及 `p‖∇u−v‖₂,₁+ratio·p‖Ev‖₂,₁`；非负方案要求u≥0。
- 建议替换：`对非负TV，归一化目标为 min_{u≥0} ½‖Bu−d‖₂²+p·TV(u)，其中u=x/R、B=A/√L、d=b/(R√L)。小波方案另加ratio·p·‖W_detail u‖₁，TGV则用相应的二阶广义总变差项替代TV。p不能与不同阶段的原始λ或PnP的ρ/σ直接比较。`
- 未施加非负约束的 `TV_control` 应明确去掉u≥0，不要将其纳入“非负TV”定义。

### 5. 第14条参考文献：文档年份应区分发表年与访问年

- 当前 bibliography 将 scikit-image 0.26 API 文档写为 `2026`，可核查的是访问日期2026-10-11；未核查文档单页的发表年份。
